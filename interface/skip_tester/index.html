Test du saut d'images

Avant l'annotation, une image dont le cosinus CLIP avec la dernière image gardée dépasse le seuil n'est pas envoyée aux annotateurs (frames.skip_refs, seuil du pipeline ). Aucun appel payant.

Le chiffre sous chaque image est son cosinus avec l'image envoyée précédente : il est resté sous le seuil.
