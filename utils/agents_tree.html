        • outiltrain_model

          Entraîne un classifieur binaire (ajout de montage visible ou non) sur des embeddings figés, sur le train du split choisi avec un rééchantillonnage (balance) et une pondération (weights) optionnels, et l'évalue sur le val de ce split. Renvoie l'id d'expérience, AUC, AP, le rappel au seuil de précision 95 % (avec FP/FN) et l'effet du rééchantillonnage et de la pondération. Les embeddings absents du cache sont calculés à la volée (GPU).

          • embeddingsrequis array de string
            Liste 'extracteur:vue', extracteurs clip_b32, clip_b16, clip_l14, dinov2_s, dinov2_b ; vues full (image entière) ou grid2 (image + 4 quadrants). Un seul élément = CLIP seul ou DINOv2 seul ; plusieurs = embeddings concaténés, ex. ['clip_b32:full', 'dinov2_s:full'] pour CLIP + DINOv2.
          • model string · logreg | mlp | hgb
          • temporal string · none | diff
            diff ajoute e_t - e_(t-1) (changement depuis l'image précédente).
          • params object
            logreg: C ; mlp: hidden (liste), alpha ; hgb: max_iter, lr, max_leaf_nodes ; tous: pca (int).
          • balance object
            Rééchantillonnage de train seulement (val et test intacts) : {groupe: facteur, 0 à 10}. Sous 1, on garde cette fraction des images ; au-dessus, on les duplique (3 = trois exemplaires). Groupes : positif, negatif, clip_vide, portrait, paysage. positif / negatif = images avec / sans ajout ; clip_vide = images des vidéos sans aucune image avec ajout ; portrait / paysage = orientation de la vidéo. Ex. {'negatif': 2, 'paysage': 0.7}. Le dataset n'est pas modifié.
          • weights object
            Poids des images de train dans la perte, sans changer les données : {groupe: poids, > 0 et au plus 10}, mêmes groupes que balance. Une image dans plusieurs groupes prend le plus grand poids, les autres gardent 1. S'ajoute à la pondération équilibrée des classes déjà appliquée (logreg, hgb). Ex. {'clip_vide': 3}.
          • note string
            Hypothèse testée, en une phrase, sans recopier la config.
          • split_idrequis string
            Split sur lequel entraîner (train) et mesurer (val) : un id renvoyé par make_split (voir list_experiments).
