        • outiltrain_model

          Entraîne un classifieur binaire (ajout de montage visible ou non) sur des embeddings figés, sur le train du split choisi avec un rééchantillonnage (balance) et une pondération (weights) optionnels, et l'évalue sur le val de ce split.           • embeddingsrequis array de string
            Liste 'extracteur:vue', extracteurs clip_b32, clip_b16, clip_l14, dinov2_s, dinov2_b ; vues full (image entière) ou grid2 (image + 4 quadrants). Un seul élément = CLIP seul ou DINOv2 seul ; plusieurs = embeddings concaténés, ex. ['clip_b32:full', 'dinov2_s:full'] pour CLIP + DINOv2.
          • model string · logreg | mlp | hgb
          • temporal string · none | diff
            diff ajoute e_t - e_(t-1) (changement depuis l'image précédente).
          • params object
            logreg: C ; mlp: hidden (liste), alpha ; hgb: max_iter, lr, max_leaf_nodes ; tous: pca (int).
          • balance object
            Rééchantillonnage de train seulement (val et test intacts) : {groupe: facteur, 0 à 10}. Sous 1, on garde cette fraction des images ; au-dessus, on les duplique (3 = trois exemplaires). Ex. {'negatif': 2, 'paysage': 0.7}. Le dataset n'est pas modifié.

            Poids des images de train dans la perte, sans changer les données : {groupe: poids, > 0 et au plus 10}, mêmes groupes que balance. Une image dans plusieurs groupes prend le plus grand poids, les autres gardent 1. S'ajoute à la pondération équilibrée des classes déjà appliquée (logreg, hgb). Ex. {'clip_vide': 3}.

| | Val (seuil 0,5053) | Test (seuil 0,5053) |

**Verdict : échec total. `exp_001` ne tient pas ses performances val sur test.** Le clip de test est une vidéo *sans aucun ajout* (15 images) ; le modèle en signale **8 comme contenant un ajout (53 % de fausses alertes)**. À précision visée 95 %, la précision réelle sur test est de 0 %. Les scores val (AUC 1,000, AP 1,000) étaient du bruit : le modèle a vraisemblablement mémorisé l'habillage de la chaîne de val plutôt qu'appris une notion générale d'« ajout ».

## 2. Analyse d'erreurs sur val (au seuil 0,5053)

- **Aucune image positive ratée** (0/22, toutes les positives sont en portrait, toutes sur la chaîne « Ezequiel - Juicio Bíblico »).
- **1 seule fausse alerte sur val** : clip `yt_ieiOR5l3lqU` (paysage), score **p = 0,51** contre un seuil de **0,5053** — marge de 0,005. L'image inspectée est une vue intérieure quelconque (porte blanche, poignée, prise électrique, parquet) : **aucun ajout visible, étiquette négative correcte, le modèle s'est trompé**, et de justesse.
- Cette fausse alerte val est le **même profil que les 8 fausses alertes test** : séquences brutes, sobres, peu texturées que le modèle note au-dessus du seuil. Sur val il n'y en avait qu'une (hasard du petit split) ; sur test elles sont majoritaires.

**Fragilité du seuil confirmée** : le seuil 0,5053 ne repose sur aucune marge robuste — la frontière passe à 0,005 près d'une fausse alerte val, et le clip test entier se situe du mauvais côté.

## 3. Recommandation

**`exp_001` n'est PAS un candidat fiable pour la mise en production.** Il a raté son test final (précision 0 % vs 95 % visé) ; il doit être exclu de la sélection de production. Les scores val étaient du bruit : val = 132 images, 22 positives, **2 clips d'une seule chaîne, une seule orientation (portrait)** — le modèle a surappris cette chaîne.

**Collecte de données (prioritaire, avant tout nouveau modèle) :**
- **Chaînes nombreuses et variées** en val/test (le split actuel n'a que 2 chaînes val / 1 test) ; jamais une seule chaîne porte toutes les positives.
- **Positives en paysage** : toutes les positives val sont en portrait, le modèle n'a donc jamais vu d'habillage paysage — c'est exactement ce qu'il confond avec du « brut » sur test.
- **Négatifs difficiles** : vidéos sans ajout mais visuellement « chargées » (intérieurs sobres, murs unis, interfaces, génériques animés, images dans l'image naturelles) — ce sont elles qui tuent la précision.
- **Diversité de styles d'habillage** : logos, cadres, textes bas d'écran, incrustations, transitions, chaînes portrait (shorts/tiktok) et paysage (vlogs, procès, podcasts).

**Pistes modèle à tester ensuite (sur un nouveau split plus gros) :**
- Composante **temporelle** (stabilité des habillages image à image) — `exp_002` allait dans ce sens mais n'a jamais été validé sur un split suffisant.
- **Mining de négatifs difficiles** et rééquilibrage (pondération ou rééchantillonnage) plutôt qu'un seuil tiré sur 132 images.
- Ne choisir le seuil que sur un val **beaucoup plus grand**, et exiger une marge minimale autour du seuil (ex. : aucune prédiction dans ±0,05 du seuil sur val).

**Bilan de session** : test final consommé sur `exp_001` (échec), analyse val faite, aucune donnée modifiée, aucun entraînement lancé. Il ne reste plus de test final dans cette session : **aucun modèle ne peut être certifié pour la production ici** ; la décision devra attendre un nouveau split et de nouvelles expériences.
