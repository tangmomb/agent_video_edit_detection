    • délègueask_dataset_builder

      Délègue une génération de données au Dataset Builder ; renvoie son rapport.

      • taskrequis string
        Consigne autonome pour l'agent.
      • agentdataset_buildermistral-large-4-0 · 12 tours max · 4 outils

        Dataset Builder : génère les vidéos synthétiques annotées et les frames étiquetées.

        • outildataset_info

          État du dataset : composition globale (vidéos, frames, taux de frames positives, frames ambiguës exclues, vidéos sans ajout, répartition des vidéos par orientation et des éléments par type, animation d'entrée, animation de sortie, surface et fond), diversité (vidéos par thème, clips sources réutilisés), liste des splits existants (volumes, note, paramètres), extracteurs d'embeddings disponibles et leur coût, budgets restants (génération, tests finaux, quotas d'API).

          aucun paramètre
        • outildata_requests

          Historique des générations passées (volume, paramètres, raison).

          aucun paramètre
        • outilgenerate_data

          Génère de nouvelles vidéos annotées, chacune sur un clip source jamais utilisé, et les ajoute au dataset, puis extrait et étiquette leurs frames. Coûteux en temps et en quota d'API d'images : justifie chaque génération.

          • nrequis integer 1…100
          • reasonrequis string
            Pourquoi ces données sont nécessaires.
          • query string
            Thème des vidéos sources en anglais (sinon aléatoire).
          • orientation string portrait | landscape
          • type_weights object
            Poids relatifs des types : keyword, question, subtitle, lower_third, image, shape, title_card
          • lang string fr | en | mix
          • empty_prob number 0…1
            Proportion de vidéos sans aucun ajout (négatifs).
        • outilexclude_videos

          Retire des vidéos de tous les splits, présents et futurs, sans supprimer de fichier. Réservé aux vidéos défectueuses ou dupliquées.

          • videosrequis object
            {sample_id: raison du défaut}
    • délègueask_model_researcher

      Délègue un lot d'expériences au Model Researcher ; renvoie son rapport.

      • taskrequis string
        Consigne autonome pour l'agent.
      • agentmodel_researchermistral-large-4-0 · 20 tours max · 4 outils

        Model Researcher : choisit les représentations et les modèles, entraîne, mène les expériences.

        • outildataset_info

          État du dataset : composition globale (vidéos, frames, taux de frames positives, frames ambiguës exclues, vidéos sans ajout, répartition des vidéos par orientation et des éléments par type, animation d'entrée, animation de sortie, surface et fond), diversité (vidéos par thème, clips sources réutilisés), liste des splits existants (volumes, note, paramètres), extracteurs d'embeddings disponibles et leur coût, budgets restants (génération, tests finaux, quotas d'API).

          • split_id string
            Ajoute la composition détaillée de train, val et test pour ce split (id renvoyé par make_split).
        • outillist_experiments

          Historique complet des expériences (toutes sessions) : split utilisé, config (embeddings, modèle, hyperparamètres, rééquilibrage de train, hypothèse), métriques val (rappel à précision 90/95/99 %, AUC, AP, ms/frame), volume de données utilisé (vidéos et frames par split, fps), date, résultat du test final.

          aucun paramètre
        • outilmake_split

          Crée un split train/val/test figé sur toutes les vidéos actuelles (les vidéos générées ensuite n'y entrent pas). Les vidéos d'un même clip source restent du même côté. Le test est commun à tous les splits (figé au premier) : seuls train et val sont redécoupés. Renvoie l'id du split et la composition de train, val et test.

          • noterequis string
            Pourquoi ce split (ce qu'il corrige ou couvre).
          • val_ratio number 0.05…0.4
            Part des clips en val (défaut 0.2).
          • test_ratio number 0.05…0.4
            Part des clips en test (défaut 0.2), pour le premier split seulement : ignoré ensuite (test figé).
          • stratify array<string>
            Caractéristiques à répartir au plus près des proportions visées dans chaque split : type (d'élément), animation (d'entrée), orientation, theme, video_vide. Par défaut toutes ; [] = tirage purement aléatoire.
          • seed integer
            Graine du tirage (défaut 0).
        • outiltrain_model

          Entraîne un classifieur binaire (ajout de montage visible ou non) sur des embeddings figés, sur le train du split choisi avec un sous-échantillonnage optionnel (balance), et l'évalue sur le val de ce split. Renvoie l'id d'expérience, le rappel (avec seuil et TP/FP/FN) aux précisions 90/95/99 %, AUC, AP et le coût de calcul (ms/frame). Les embeddings absents du cache sont calculés à la volée (GPU).

          • featuresrequis array<string>
            Liste 'extracteur:vue', extracteurs clip_b32, clip_b16, clip_l14, dinov2_s, dinov2_b ; vues full (image entière) ou grid2 (image + 4 quadrants). Un seul élément = CLIP seul ou DINOv2 seul ; plusieurs = embeddings concaténés, ex. ['clip_b32:full', 'dinov2_s:full'] pour CLIP + DINOv2.
          • model string logreg | mlp | hgb
          • temporal string none | diff
            diff ajoute e_t - e_(t-1) (changement depuis la frame précédente).
          • params object
            logreg: C ; mlp: hidden (liste), alpha ; hgb: max_iter, lr, max_leaf_nodes ; tous: pca (int).
          • balance object
            Sous-échantillonnage de train seulement (val et test intacts) : {groupe: fraction de frames gardée, 0 à 1}. Groupes : keyword, question, subtitle, lower_third, image, shape, title_card, negatif, video_vide, portrait, paysage. Un type d'élément = frames positives dont tous les ajouts visibles sont de ce type ; negatif = frames sans ajout ; video_vide = frames des vidéos sans aucun ajout. Ex. {'subtitle': 0.5, 'negatif': 0.7}. Le dataset n'est pas modifié.
          • note string
            Hypothèse testée.
          • split_idrequis string
            Split sur lequel entraîner (train) et mesurer (val) : un id renvoyé par make_split (voir dataset_info).
    • délègueask_evaluator

      Délègue une évaluation, une analyse d'erreurs ou un test final à l'Evaluator ; renvoie son rapport.

      • taskrequis string
        Consigne autonome pour l'agent.
      • agentevaluatormistral-large-4-0 · 15 tours max · 4 outils

        Evaluator / Error Analyst : mesure, analyse les erreurs, vérifie et promeut les améliorations.

        • outillist_experiments

          Historique complet des expériences (toutes sessions) : split utilisé, config (embeddings, modèle, hyperparamètres, rééquilibrage de train, hypothèse), métriques val (rappel à précision 90/95/99 %, AUC, AP, ms/frame), volume de données utilisé (vidéos et frames par split, fps), date, résultat du test final.

          aucun paramètre
        • outilanalyze_errors

          Au seuil qui atteint la précision visée sur val : rappel, TP/FP/FN, taux de frames positives ratées par type d'ajout, surface, fond, animation d'entrée, phase (entrée ou sortie en cours, repos), nombre d'ajouts et orientation ; répartition des fausses alertes ; exemples de frames ratées.

          • experiment_idrequis string
          • precision number
            Précision visée sur val, qui fixe le seuil (défaut 0.95).
        • outilshow_examples

          Montre des frames de val, ajouts encadrés en rouge : frames avec ajout ratées (kind=missed) ou fausses alertes (kind=false_positive).

          • experiment_idrequis string
          • kind string missed | false_positive
          • n integer 1…6
          • precision number
            Précision visée sur val, qui fixe le seuil (défaut 0.95).
        • outilfinal_test

          Évalue une expérience sur le test de son split avec le seuil choisi sur val : rappel, précision, TP/FP/FN, AUC, AP. Nombre d'appels limité par session : à réserver au candidat final.

          • experiment_idrequis string
          • precision number
            Précision visée sur val, qui fixe le seuil (défaut 0.95).
